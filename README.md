# 🚗 자동차 경주

## 도메인 흐름

- 'Cars' : 여러 대의 자동차(Car 객체)를 관리하고, 이동과 우승자를 계산한다.
- 'Car' : 자동차 1대를 나타내는 객체로, 속성으로 'Name'과 'Positon'을 가진다.
- 'Name' : 자동차 이름을 나타내며, 이름에 대한 검증(공백, 길이 등)을 관리한다.
- 'Position' : 자동차의 위치를 나타내며, 위치 값을 저장하고 증가시키는 기능을 가진다.

## ⚙️ 기능 목록 구현

- 입력
    - [x] 쉼표(,) 기준으로 자동차를 입력받는다.
    - [x] 시도 횟수를 입력받는다.

- 게임 진행 
    - [x] 자동차 이름을 쉼표(,)를 기준으로 구분한다.
    - [x] 움직이는 조건인 0~9 무작위 값을 뽑는다.
    - [x] 무작위 숫자가 4 이상이면 움직이고 4 미만이면 움직이지 않는다.
    - [x] 각 라운드별 자동차의 위치 상태를 기록한다.
    - [x] 가장 멀리 간 자동차를 우승자로 판별한다.

- 출력
    - [x] 자동차 이름 입력 안내 문구를 출력한다.
    - [x] 시도 횟수 입력 안내 문구를 출력한다.
    - [x] 실행 결과(각 라운드별 위치 상태)를 출력한다.
    - [x] 게임 종료 후 우승자를 출력한다.


## 예외 처리

- 입력이 비어있는 경우, 예외를 발생시킨다.
- 자동차 이름이 5자 초과인 경우, 예외를 발생시킨다.
- 시도 횟수가 0보다 작을 경우, 예외를 발생시킨다.
- 시도 횟수가 숫자가 아닐 경우, 예외를 발생시킨다.

## 설계 구조

- utils 
    - InputParser : 쉼표(,) 기준으로 자동차 이름을 구분하고 Name 객체로 변환한다.
    - RandomNumberGenerator : 0~9 사이의 랜덤값을 생성한다.  

- domain
    - Car : 자동차 객체를 생성하고, 이름(Name)과 위치(Position)를 관리한다.
    - Cars : 여러 대의 Car 객체를 관리하며, 이동과 우승자를 계산한다.
    - Position : 자동차의 현재 위치를 저장하고 증가시킨다.
    - PositionCondition : 이동 조건(랜덤값이 4 이상일 때 이동)을 관리한다.
    - Name : 자동차 이름을 저장하고, 검증을 수행한다.
    - TryCount : 시도 횟수를 관리하며, 검증을 수행한다.

- view
    - InputView : 사용자로부터 자동차 이름과 시도 횟수를 입력받는다.
    - OutputView : 각 라운드별 이동 상태와 최종 우승자를 출력한다.

- RacingComtroller : view와 domain을 연결하며, 게임의 전체 흐름을 관리한다.
